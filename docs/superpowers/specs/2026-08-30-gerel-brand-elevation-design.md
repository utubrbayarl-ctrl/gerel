# ГЭРЭЛ — Брэнд түрүүлсэн дахин төрөлт (v2 дизайн)

**Огноо:** 2026-08-30
**Статус:** Батлагдсан дизайн (Хувилбар A)

## Суурь нөхцөл

- **Зорилго:** гэрэл импортолж зардаг жинхэнэ дэлгүүрийн танилцуулга сайт. Худалдаа (сагс, төлбөр) сайт дээр явахгүй — зөвхөн барааны танилцуулга.
- **Зорилтот хэрэглэгч:** (1) шинэ байранд орж буй хүмүүс, (2) барилгын компаниуд.
- **Шийдэх асуудал:** v1 «хуурамч, яаруу хийсэн» мэдрэмж төрүүлдэг. Эх үүсвэр нь: SVG зураг бодит биш, брэндийн гүн дутуу, туршлагын функц дутуу.
- **Брэндийн мэдрэмж:** тансаг, дулаан — showroom-д орсон юм шиг.
- **Бодит барааны өгөгдөл:** хараахан байхгүй. Түр хугацаанд AI-аар бодит харагдах зураг үүсгэнэ; бодит зураг ирэхэд файл солиход л хангалттай байхаар зохион байгуулна.
- **Хамрахгүй (YAGNI):** сагс, төлбөр, хэрэглэгчийн бүртгэл, wishlist, харьцуулалт, чат, CMS/админ. CMS-ийг бодит бараа орж ирэх дараагийн шатанд авч үзнэ.

## Хэсэг 1: Брэнд identity

### Нэр, лого

- Брэндийн албан нэр: **Tes Sky** (кодод одоо байгаа нэр — хэрэглэгч баталсан; «ГЭРЭЛ» нь зөвхөн repo/төслийн кодын нэр).
- Лого: serif дисплэй фонтоор бичсэн «TES SKY» wordmark + гэрлийн цэг тэмдэг — туяа сацруулсан жижиг цэг («Sky»-гийн тэнгэрт гэрэлтэх од/гэрлийн эх үүсвэрийн утга). SVG.
- 2 хувилбар: цайвар фонд бараан (ink), бараан фонд алтлаг-cream.
- Хэрэглэх газар: header, footer, favicon, OG зураг.

### Tagline, түүх

- Албан tagline: **«Гэрэл орон зайг өөрчилнө»** (hero дээрх одоогийн өгүүлбэрийг брэндийн tagline болгож бэхжүүлнэ).
- About хуудсыг бодит бизнесийн өнцгөөс дахин бичнэ: импортын эх үүсвэр, чанарын шалгуур, «шинэ гэрт тань дулаан уур амьсгал» амлалт.
- Барилгын компаниудад зориулсан итгэлийн блок: хамтын ажиллагааны зарчим, баталгаа, хүргэлт.

### Өнгөний гүнзгийрүүлэлт

- Одоогийн cream/terracotta токен (Claude DESIGN.md) суурь хэвээрээ.
- **Бараан «showroom» section** нэмнэ: `surface-dark` (#181715) фонтой хэсгүүд — нүүр хуудсанд дор хаяж 2 section бараан болно.
- Алтлаг акцент `#e8a55a` = «гэрлийн туяа» өнгө: glow, hover, badge-д системтэй хэрэглэнэ.

- Шинэ өнгө зохиохгүй — байгаа токеныг л гүнзгийрүүлж хэрэглэнэ.

### Дуу хоолой

- «Худалдагч» биш «зөвлөх» аялгуу: мэргэжлийн-халуун дулаан. Жишээ: «Хямд!» биш «Таны зочны өрөөнд 2700K дулаан гэрэл тохирно».

## Хэсэг 2: AI photorealistic зураг

### Хамрах хүрээ

Одоогийн 116 SVG бүгд солигдоно:

| Төрөл | Тоо |
|---|---|

### Стилийн тодорхойлолт (style bible)

Зураг үүсгэхээс өмнө бичиж батлана. Бүх prompt үүнээс үүснэ — 116 зураг нэг брэндийн каталог шиг харагдах баталгаа.

- **Студи зураг:** дулаан cream (#f5f0e8 орчим) фон, зөөлөн сүүдэр, гэрэл **асаалттай** (2700K дулаан туяа харагдана), доод талдаа зөөлөн тусгал. Харьцаа 3:4.
- **Орчны зураг:** орчин үеийн монгол шинэ байрны интерьер (цагаан хана, модон шал), үдшийн бүрий, гэрэл өрөөг дулаанаар гийгүүлнэ — «энэ миний ирээдүйн гэр» мэдрэмж. Харьцаа 4:3 эсвэл 16:9.
- **Hero зураг:** бараан амбьент, гэрэл гол дүрд — showroom мэдрэмж.

### Ажлын урсгал

- Үндсэн хэрэгсэл: fal.ai (Nano Banana) — script-ээр багцлан үүсгэнэ. (fal.ai ажиллахгүй тохиолдолд л өөр image-gen руу шилжинэ.)
- Одоогийн `scripts/generate-images` бүтэцтэй адил: барааны нэр/төрөл/өнгөнөөс prompt угсарч → үүсгэж → `public/images/`-т буулгана.
- Чанар муутайг гараар шүүж дахин үүсгэнэ.
- WebP болгож optimize хийнэ (одоогийн `unoptimized` горимоос гарна).

### Ирээдүйн шилжилт

Бодит барааны зураг ирэхэд файлыг л солино — код өөрчлөгдөхгүй. Зургийн зам repository давхаргад салангид байгаа.

## Хэсэг 3: Туршлагын функцууд

### 1. Гэрэлтүүлгийн тооцоолуур — `/tooluur`

- Оролт: өрөөний төрөл, талбай (м²), таазны өндөр.
- Гаралт: шаардлагатай нийт люмен, санал болгох гэрлийн тоо, тохирох Kelvin, нийцэх барааны линкүүд.
- Бүхэлдээ client-side; люкс стандартын хүснэгт data layer-т орно. SSG хэвээр.
- Тооцооны логик бүрэн unit тесттэй.

### 2. Warm/Cool interactive үзүүлэн

- Нүүр хуудасны KelvinGuide-ийг орлоно.
- Өрөөний нэг зураг дээр слайдер: 2700K → 6500K чирэхэд гэрэл дулаанаас хүйтэн рүү шилжинэ.
- Нэг зураг + CSS overlay/blend давхарга (олон зураг ачаалахгүй). Гар утсан дээр ажиллана.

### 3. B2B хуудас — `/b2b` («Барилгын компаниудад»)

- Агуулга: бөөний нөхцөл, төслийн хамтын ажиллагааны урсгал (зураг төсөл → сонголт → нийлүүлэлт), баталгаа/хүргэлтийн амлалт, санал хүсэх форм.
- Форм: backend-гүй тул Formspree/Web3Forms маягийн үнэгүй үйлчилгээгээр имэйл рүү.
- Header-т тусдаа цэс болно.

### 4. Зөвлөгөө/журнал — `/zovlogoo`

- 6 нийтлэл (markdown → SSG рендер), нийтлэл бүр холбоотой бараагаа санал болгоно:
  1. Шинэ байрны гэрэлтүүлгийг өрөө өрөөгөөр төлөвлөх нь
  2. 2700K гэж юу вэ
  3. Таазны өндөрт тохирсон дүүжин сонгох
  4. LED-ийн наслалт ба чанар
  5. Барилгын төсөлд гэрэлтүүлэг тооцох
  6. Гэрлээр орон зайг томруулах
- SEO-гийн гол хөдөлгүүр.

## Хэсэг 4: Motion/интеракц

Бүх анимаци нэг метафорт захирагдана: **гэрэл асаж байгаа мэт**.

- Section scroll-д орж ирэхдээ зөөлөн гийнэ (opacity + бага зэрэг өгсөх) — IntersectionObserver + CSS transition.
- Барааны карт hover: зургийн glow нэмэгдэж, сүүдэр дулаан болно.
- Hero: хуудас ачаалахад гэрэл бүдэгхэнээс аажим гийнэ (0.8s, нэг удаа).
- Бараан section-уудад алтлаг туяаны gradient зөөлөн хөдөлнө.
- `prefers-reduced-motion` бүрэн хүндэтгэнэ.
- GSAP/Framer Motion **авахгүй** — CSS + IntersectionObserver хангалттай.

## Техник төлөвлөгөө

### Архитектур

Одоогийн бүтэц хэвээрээ: Next.js 16 SSG, repository давхарга, mock data. Нэмэгдэх:

- `src/lib/calculator/` — тооцоолуурын цэвэр функцууд + тест
- `src/content/articles/` — журналын markdown
- `src/components/b2b/`, `src/components/calculator/` — шинэ компонентууд
- `scripts/generate-images/` — AI зургийн pipeline (SVG generator-ийг орлоно)

### Алдааны хамгаалалт

- Тооцоолуур: оролт бүрэн validate (талбай 1–500 м², сөрөг/хоосон утга ойлгомжтой мессежтэй).
- B2B форм: client-side validation; илгээлт амжилтгүй бол ойлгомжтой алдаа + утасны дугаар fallback.

### Тест

- Одоогийн 61 unit + 3 e2e дээр нэмнэ: тооцоолуурын логик (гол + захын утгууд), Kelvin слайдер, B2B форм validation, шинэ хуудсуудын e2e smoke.
- 80%+ coverage хадгална.
